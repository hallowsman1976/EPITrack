# แอปเป็นที่บันทึกการฉีดหลัก แต่อ่าน JHCIS อย่างเดียว และมีหน้ารอลง JHCIS

ผู้ใช้ต้องการให้ EPITrack เป็นที่บันทึกการฉีดวัคซีนเด็กหลัก (เก็บ lot, วันหมดอายุ, ผู้ฉีด, สถานที่ฉีด ได้ครบ) แต่ HDC, HIS Gateway และ 43 แฟ้ม รับข้อมูลวัคซีนจาก `visitepi` ของ JHCIS เท่านั้น เราเลือกให้แอปเก็บรายการฉีดในฐานข้อมูลของตัวเอง และ **ไม่เขียนลง JHCIS** การเขียน `visitepi` จากภายนอกต้องสร้างครั้งรับบริการ (`visit`/`visitno`) ให้ถูกตามตรรกะของ JHCIS ถ้าผิดข้อมูลจะเพี้ยนโดยไม่มีใครรู้ (เหตุผลเดียวกับ ADR 0001 ของ EPI2027) แทนที่จะเขียน แอปเทียบกับ `visitepi` แบบสด แล้วแสดงหน้า "รอลง JHCIS" ให้เจ้าหน้าที่คีย์ใน JHCIS รายการจะหายจากหน้านั้นเองเมื่อพบใน JHCIS

## Consequences

- การฉีดที่ที่นี่ต้องบันทึกสองที่ (แอปและ JHCIS) หน้ารอลง JHCIS มีไว้กันข้อมูลหลุดจาก HDC
- ประวัติวัคซีนคือ `visitepi` รวมกับรายการในแอป ไม่นำเข้าข้อมูลเก่ามาเก็บในแอป ถือว่าตรงกันเมื่อเป็นคนเดียวกัน ชุดวัคซีนเดียวกัน และวันเดียวกัน ถ้าวันที่ต่างกันให้คนตรวจ
- รายการที่สถานที่ฉีดเป็น รพ. / เอกชน / ไม่ทราบ ไม่ต้องลง JHCIS
- นัดเก็บในแอปเท่านั้น ไม่เขียน `visitepiappoint`
