# mapping จากรหัส JHCIS ตรงไปที่ชุดวัคซีน และนับเข็มที่จากลำดับการฉีด

แผนเดิมคือแปลงรหัส JHCIS ผ่าน `_hdc_epi_mapping` เป็นรหัสมาตรฐาน 3 หลักก่อน แต่ตารางนั้นในฐานข้อมูลจริงไม่มีรหัสที่ใช้อยู่ตอนนี้ เช่น `D21`–`D23` (DTP-HB-Hib), `I11`/`I12` (IPV), `R11`–`R23` (Rota), `P21`–`P24` (PCV) เราจึงทำ mapping จาก **รหัสวัคซีนของ JHCIS ไปที่ชุดวัคซีนโดยตรง** และ **ไม่ใช้เลขท้ายรหัสเป็นเข็มที่** แต่นับเข็มจากลำดับวันที่ของการฉีดที่ผ่านเกณฑ์อายุและระยะห่าง เพราะรหัสเดิมกับรหัสใหม่ปนกันในเด็กคนเดียว (เช่น OPV1 กับ I11) และบางรหัสตั้งชื่อตามช่วงอายุเก่า (MMR2 "อายุ 2 ปีครึ่ง")

## Consequences

- รหัสหนึ่งนับได้หลายชุดวัคซีน (เช่น `D51` DTP-IPV-HB-Hib นับทั้ง DTP-HB-Hib และโปลิโอ) mapping จึงเป็นรายการคู่ รหัส–ชุดวัคซีน
- รหัส Rota ระบุชนิดผลิตภัณฑ์ (RV1 ฉีด 2 เข็ม, RV5 ฉีด 3 เข็ม) ไว้ใน mapping เพื่อให้รู้ว่าชุดครบหรือยัง
- การเทียบ "ลง JHCIS แล้ว" ใช้คน + ชุดวัคซีน + วันที่ ไม่ใช้เลขเข็ม
- รหัสใหม่ที่ JHCIS เพิ่มในอนาคต ผู้ดูแลต้องเพิ่มใน mapping เอง หน้า mapping แสดงรหัสที่มีการฉีดแต่ยังไม่ได้ map
