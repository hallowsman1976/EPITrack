# เก็บข้อมูลของแอปในฐานข้อมูล MySQL `epitrack` บนเซิร์ฟเวอร์เดียวกับ JHCIS

แอปรันบนเครื่องเดียว และเครื่องอื่นในวง LAN เปิดผ่านเบราว์เซอร์ เราเลือกเก็บรายการฉีด นัด ผู้ใช้ และประวัติการแก้ไข ในฐานข้อมูล MySQL ชื่อ `epitrack` แยกจาก `jhcisdb` บนเซิร์ฟเวอร์เดียวกัน แทน SQLite เพราะเซิร์ฟเวอร์ JHCIS เปิดอยู่ตลอดและสำรองเป็นกิจวัตร และย้ายเครื่องที่รันแอปได้โดยไม่ต้องย้ายไฟล์ข้อมูล ใช้การเชื่อมต่อ 2 ชุด: `jhcisdb` ผ่านตัวกันที่ยอมให้ SELECT เท่านั้น และ `epitrack` ที่อ่านเขียนได้

## Consequences

- user ของ MySQL ต้องมีสิทธิ์ CREATE DATABASE ตอนเปิดใช้ครั้งแรก แอปสร้างฐานข้อมูลและตารางเอง และอัปเกรดตารางตาม `schema_version`
- เซิร์ฟเวอร์ JHCIS เป็น MySQL 5.6 จึงไม่ใช้ชนิด JSON หรือ CTE (`WITH`) และคีย์ที่เป็นข้อความยาวไม่เกิน 191 ตัวอักษร (utf8mb4)
- โปรแกรมสำรองข้อมูลของ JHCIS ไม่สำรอง `epitrack` แอปจึงสำรองเอง (dump เป็นไฟล์ .sql วันละครั้ง เก็บ 30 ชุด ใน `backups\`)
